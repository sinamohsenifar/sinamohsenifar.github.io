Open source · MCP · Firefox

FoxBridge

↗

MCP server و Firefox extension به‌صورت local-first که به دستیار هوش مصنوعی اجازه می‌دهد session واقعی و login‌شدهٔ Firefox را تحت کنترل کاربر بخواند و هدایت کند.
